# Tour

A tour of Lerta for programmers who know another language. Each page shows one topic in short programs, with what they print, and links to [the reference](../reference/README.md) for the rules.

| Page | Topic |
|---|---|
| [Basics](basics.md) | Names, types, strings and comments |
| [Functions](functions.md) | Functions, their arguments and function values |
| [Control flow](control-flow.md) | `if`, postfix forms, `then`/`else` and `case` |
| [Collections](collections.md) | Arrays, maps, sets, `for` and comprehensions |
| [Structs](structs.md) | Structs, their construction and `extend` |
| [Classes and memory](classes.md) | Classes, reference counting and weak references |
| [Interfaces](interfaces.md) | Interfaces and generic functions |
| [Optional values](optional-values.md) | `T?`, narrowing, `else`, `?.` and `!` |
| [Enums and unions](enums-and-unions.md) | Enums, unions and `case` on them |
| [Errors](errors.md) | Exceptions, the runtime's errors and `try` |
| [Modules](modules.md) | Imports, exports and the standard modules |
| [Async](async.md) | `await`, promises and the event loop |
| [Tools](tools.md) | The `lerta` command, editors, and where to go next |
