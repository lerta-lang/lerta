# Tour

A tour of Lerta for programmers who know another language. Each page shows one topic in short programs, with what they print, and links to [the reference](../reference/README.md) for the rules.

| Page | Topic |
|---|---|
| [basics.md](basics.md) | Names, types, strings and comments |
| [functions.md](functions.md) | Functions, their arguments and function values |
| [control-flow.md](control-flow.md) | `if`, postfix forms, `then`/`else` and `case` |
| [collections.md](collections.md) | Arrays, maps, sets, `for` and comprehensions |
| [structs.md](structs.md) | Structs, their construction and `extend` |
| [classes.md](classes.md) | Classes, reference counting and weak references |
| [interfaces.md](interfaces.md) | Interfaces and generic functions |
| [optional-values.md](optional-values.md) | `T?`, narrowing, `else`, `?.` and `!` |
| [enums-and-unions.md](enums-and-unions.md) | Enums, unions and `case` on them |
| [errors.md](errors.md) | Exceptions, the runtime's errors and `try` |
| [modules.md](modules.md) | Imports, exports and the standard modules |
| [async.md](async.md) | `await`, promises and the event loop |
| [tools.md](tools.md) | The `lerta` command, editors, and where to go next |
